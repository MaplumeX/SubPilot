## Priority Issues

### [P1] fetch catch 块吞错误，渲染虚假空状态/all-clear — 品牌损害最大
- **What**：`DashboardPage.fetchData` 和 `SubscriptionsPage.fetchSubscriptions` 的 `catch` 块吞掉所有非 401 错误。加载失败时，`stats`/`subscriptions` 保持 null/[]，UI 渲染"本月暂无到期"或"暂无订阅" —— 把"我不知道"呈现为"你安全"。
- **Why it matters**：PRODUCT.md 原则 2"数字要能被信任。信任一旦动摇，工具就失效。"一个因网络错误显示"all clear"的财务工具是危险的。
- **Fix**：加 error state + Retry CTA。catch 中 setError(true)，UI 在 error 时显示"加载失败，点击重试"而非空状态。
- **Suggested command**：`harden`

### [P1] Dashboard acknowledge 按钮漏改 CheckCircle2 图标
- **What**：R3 fix #5 给表格和卡片视图的 acknowledge 按钮加了 `CheckCircle2 text-pending` 图标，但 Dashboard due-soon 列表的 acknowledge 按钮（第三处 surface）漏了。
- **Why it matters**：同一动作三处 surface，两处有图标一处没有 —— 一致性漂移。Dashboard 是最显眼的一处。
- **Fix**：给 Dashboard acknowledge Button 加 `<CheckCircle2 className="size-4 text-pending" />`。
- **Suggested command**：`polish`

### [P2] Statistics donut + 图例数据重复
- **What**：PieChart 展示分类分布，下方图例列表重复显示同样的分类+百分比+金额。
- **Why it matters**：违反 DESIGN.md"少即是足够"和 anti-reference"不做图表展示型 dashboard"。同一信息两次呈现。
- **Fix**：保留图例列表（有文字 fallback 更可读），移除 donut 或反之。推荐保留图例移除 donut。
- **Suggested command**：`distill`

### [P2] NotificationsCard SMTP/Telegram 凭据在主 Settings 滚动上全视觉权重
- **What**：SMTP host/port/user/password + Telegram token/chat-id 内联在 Settings 主滚动上，对非技术用户是认知悬崖。
- **Why it matters**：cognitive cliff —— 大量技术字段无折叠无帮助文本。
- **Fix**：折叠在 switch 后面 + 加 plain-language helper + 考虑 /settings/notifications 独立路由。
- **Suggested command**：`layout`

### [P3] NextMonthProjection 返回 null 导致布局位移
- **What**：`NextMonthProjection` 在延迟的 useEffect setState 期间返回 null，造成布局位移。
- **Why it matters**：CLS（布局位移）影响体验。
- **Fix**：改为 useMemo 或加 skeleton 占位。
- **Suggested command**：`optimize`
