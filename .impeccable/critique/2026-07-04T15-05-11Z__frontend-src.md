## Priority Issues

### [P0] EntityManagerCard 删除绕过自己的 ConfirmDialog（死代码）— 已修复
- **What**：trash 按钮 `onClick={() => handleDelete(entity.id)}` 直接调 API 删除。`deleteTarget` state + `<ConfirmDialog>` 已加但 `setDeleteTarget` 从未被 trash 按钮调用，dialog 的 `open` 永远 false。
- **Why it matters**：删除分类/支付方式不可逆，可能被引用订阅阻止。零确认是数据安全 bug。
- **Fix**：已修复 —— trash 按钮改为 `onClick={() => setDeleteTarget(entity)}`，复用已有 ConfirmDialog。
- **State**：✅ 本轮已修

### [P1] EntityManagerCard 操作无成功反馈
- **What**：`handleCreate` / `commitRename` / `handleDelete` 调 API 后静默 `reload()`，无 toast。用户看列表"可能变了"但无明确确认。
- **Why it matters**："可靠"要求用户*知道*操作已落地。P0 修复后删除成功关闭 dialog 无肯定信号仍低于标准。
- **Fix**：加 success toast（复用 `ui/toaster`）至 create/rename/delete 成功后。
- **Suggested command**：`clarify`

### [P2] Statistics `top3Subtitle` 是标题的重复
- **What**：`top3Subtitle` = "Top 3 Share" / "Top 3 占比"（中英混用），与 `top3Percentage` 卡片标题意思完全相同。副标题位被浪费。
- **Why it matters**：副标题应澄清指标（如"占月度总支出"），不是重述名称。中英混用是 polish 缺陷。
- **Fix**：改为 "of total monthly spend" / "占月度总支出"。
- **Suggested command**：`clarify`

### [P2] 删除按钮样式在表格和卡片视图间不一致
- **What**：表格删除 = `variant="destructive"` 红色图标（总是红、总可见）；卡片删除 = `variant="ghost"` + muted hover 变红（静默态不显眼）。
- **Why it matters**：同一破坏性动作呈现两种视觉严重度。表格的常红图标是最抢眼的元素，对非时间敏感动作微妙违反"平稳"。卡片的 muted-then-red 更克制更符合品牌。
- **Fix**：统一表格删除为 `ghost` + `text-muted-foreground hover:text-destructive`，与卡片一致。
- **Suggested command**：`harden`

### [P3] NextMonthProjection 接收未使用的 locale 和 baseCurrency props
- **What**：Dashboard 传 `locale` 和 `baseCurrency` 给 NextMonthProjection，但组件只解构 `{ subscriptions, fmt }`。
- **Why it matters**：死参数，不完整重构的痕迹。
- **Fix**：移除两个 props，或前缀 `_`。
- **Suggested command**：`polish`
