## Detailed Findings by Severity

### [P1] 表格排序表头不可键盘操作
- **Location**: `pages/SubscriptionsPage.tsx:64-80` (SortableHeader)
- **Category**: Accessibility
- **Impact**: 键盘用户无法聚焦表头触发排序，完全无法使用此功能
- **WCAG**: 2.1.1 Keyboard (Level A) — 违反
- **Recommendation**: `<TableHead>` 内包裹 `<button>`，或加 `tabIndex={0}` + `onKeyDown` 处理 Enter/Space。当前 `aria-sort` 正确但无法激活
- **Suggested command**: `/impeccable audit`

### [P1] Switch 触控目标过小
- **Location**: `components/ui/switch.tsx:17` — default `h-[18.4px] w-[32px]`，sm `h-[14px] w-[24px]`
- **Category**: Accessibility / Responsive
- **Impact**: 移动端用户难以准确切换；运动障碍用户误触相邻控件。`after:-inset-x-3 after:-inset-y-2` 扩大了 hit area 但视觉目标仍太小，不满足感知尺寸要求
- **WCAG**: 2.5.5 Target Size (Level AAA) 建议 44×44px；2.5.8 Target Size Minimum (Level AA) 要求 24×24px — default 满足 AA 但 sm（14×24px）不满足
- **Recommendation**: default 提到 24×44px 视觉尺寸；sm 变体至少 24×24px。或保留视觉小尺寸但确保 hit area（`after` 伪元素）≥44px 且有视觉焦点环
- **Suggested command**: `/impeccable adapt`

### [P1] CalendarPage 移动端事件拥挤
- **Location**: `pages/CalendarPage.tsx:438,464` — `text-[10px]` 事件标签 in 7 列网格
- **Category**: Responsive Design
- **Impact**: 窄屏（< 400px）每列 ~50px，10px 字 + `px-1 py-0.5` padding 导致事件名截断到 3-4 字符，用户无法辨认是哪个订阅
- **WCAG**: 1.4.4 Resize Text (Level AA) — 10px 低于 14px 最小可读
- **Recommendation**: 移动端用 `sm:text-[10px]` 但 base 用更大的最小尺寸（12px），或移动端切换为 list 视图而非 grid。或用 `min-w-0` + `truncate` 配合更大的触控区域
- **Suggested command**: `/impeccable adapt`

### [P2] auto_renew 仅图标无可见 label
- **Location**: `pages/SubscriptionsPage.tsx:395-401`，`components/SubscriptionCard.tsx:85-90`
- **Category**: Accessibility
- **Impact**: 屏幕阅读器读 "RefreshCw 图标"，无 "自动续费开/关" 语义。触摸设备无 hover，`title` tooltip 不可达
- **WCAG**: 1.1.1 Non-text Content (Level A) — 功能性图标需 text alternative
- **Recommendation**: 加 `aria-label={sub.auto_renew ? t("subscriptions.auto_renew_enabled") : t("subscriptions.auto_renew_disabled")}` 或用可见文字 "是/否"
- **Suggested command**: `/impeccable clarify`

### [P2] logo 搜索结果按钮无 aria-label
- **Location**: `components/SubscriptionForm.tsx:399-411`
- **Category**: Accessibility
- **Impact**: `<img alt="">` 空 alt + `<button>` 无 aria-label，屏幕阅读器读 "按钮" 无上下文
- **WCAG**: 1.1.1 Non-text Content；4.1.2 Name, Role, Value
- **Recommendation**: `<button aria-label={t("subscriptionForm.selectLogo", { domain: candidate.domain })}>` 或用 `candidate.domain` 作 label
- **Suggested command**: `/impeccable audit`

### [P2] StatisticsPage loading/empty 与全局不一致
- **Location**: `pages/StatisticsPage.tsx:138-141` (loading)，`158-172` (empty)
- **Category**: Consistency (状态一致性 — 用户优先②)
- **Impact**: loading 仅一行 muted 文字，其他页用 skeleton；empty 无引导 CTA，其他页有按钮
- **Recommendation**: loading 改为 chart 区域 skeleton（280px 高 pulse + 列表 skeleton）。empty 加 "添加第一个订阅" 按钮
- **Suggested command**: `/impeccable polish`

### [P2] AppLayout nav 移动端无收起
- **Location**: `components/AppLayout.tsx:86-104`
- **Category**: Responsive Design
- **Impact**: 5 个 nav 项 + logo + theme toggle + user email + sign out 在窄屏 `flex-wrap` 多行堆叠，header 变高挤压主内容
- **Recommendation**: < 640px 时收起为 hamburger menu 或 bottom tab bar；当前 `flex-wrap` 是临时方案
- **Suggested command**: `/impeccable adapt`

### [P2] SettingsPage 卡片宽度不一致
- **Location**: `pages/SettingsPage.tsx` — 语言/货币/分类/支付方式卡 `max-w-md`，通知卡 `max-w-lg`
- **Category**: Theming / Layout
- **Impact**: 视觉节奏断裂，同一页面的卡片宽度应统一
- **Recommendation**: 通知卡改 `max-w-md`，或所有卡统一 `max-w-lg`（通知卡字段多，可能 lg 是合理的 —— 那么其他卡也应 lg 或说明为何不同）
- **Suggested command**: `/impeccable layout`

### [P2] icon-sm / icon-xs 按钮触控目标 < 44px
- **Location**: `components/ui/button.tsx:30-32` — icon-sm `size-7` (28px)，icon-xs `size-6` (24px)
- **Category**: Accessibility / Responsive
- **Impact**: 移动端触控目标偏小，误触风险。calendar prev/next、表格行删除/编辑按钮都用 icon-sm
- **WCAG**: 2.5.8 Target Size Minimum (Level AA) 24×24px — icon-xs 刚好达标，icon-sm 达标但偏小
- **Recommendation**: 移动端用 `sm:size-9`（36px）或 `sm:size-11`（44px），桌面保持 28px。或确保 hit area 通过 padding 扩展
- **Suggested command**: `/impeccable adapt`

### [P3] StatisticsPage heading 层级不一致
- **Location**: `pages/StatisticsPage.tsx:147` (no-data 态 `h2` with `clamp`) vs `164` (正常态 `h2` with `text-2xl`)
- **Category**: Consistency
- **Impact**: 同一页面两种 heading 尺寸，no-data 态用了 fluid clamp（DESIGN.md product register 建议 fixed rem），正常态用 fixed
- **Recommendation**: 统一为 `text-2xl`，删除 clamp（DESIGN.md: "Fixed rem scale, not fluid"）
- **Suggested command**: `/impeccable typeset`

### [P3] CalendarPage out-of-month 日期对比度极低
- **Location**: `pages/CalendarPage.tsx:381` — `text-muted-foreground/35`
- **Category**: Accessibility
- **Impact**: 35% 透明度的 muted-foreground 对 background 约 1.5:1，远低于 4.5:1。但这些是装饰性 out-of-month 日期，不承载操作信息
- **WCAG**: 1.4.3 Contrast (Level AA) — 装饰性文字豁免，但当前 35% 可能过低导致完全不可见
- **Recommendation**: 提到 `/50` 或 `/60`，保持 recessed 但可辨认
- **Suggested command**: `/impeccable audit`

### [P3] ConfirmDialog onConfirm 无错误反馈
- **Location**: `components/ConfirmDialog.tsx:39` — `void onConfirm()`
- **Category**: Error Recovery
- **Impact**: 如果 confirm 是 async 且失败（如删除 409 in-use），dialog 关闭但用户无反馈
- **Recommendation**: `onConfirm` 返回 Promise，失败时保持 dialog open + 显示错误
- **Suggested command**: `/impeccable harden`

## Patterns & Systemic Issues

1. **触控目标系统性偏小**: Switch (18px)、icon-sm (28px)、icon-xs (24px) —— 整个组件库的 small variant 都为桌面密度优化，移动端未适配。需要一个 mobile-first 的触控目标策略。

2. **状态词汇分裂**: 4 个页面 3 种 loading 模式（skeleton / 一行文字 / 无），3 种 empty 模式（图标+CTA / 仅文字 / 仅文字+CTA）。需要统一为一个 LoadingState / EmptyState 组件。

3. **图标按钮缺 aria-label 覆盖**: 多处 icon-only 按钮依赖 `aria-label` props，但部分调用未传（logo 搜索结果）。需要一个 lint 规则或默认 fallback。

---

## Positive Findings

1. **Skip link 实现正确** — `AppLayout.tsx:80-85` 有 `sr-only focus:not-sr-only` skip link，keyboard 用户可跳过 nav
2. **Skeleton 占位完整** — Dashboard / Subscriptions / Calendar 都用 `animate-pulse` skeleton + `role="status" aria-live="polite"`
3. **Reduced-motion 全局覆盖** — `index.css` 的 `@media (prefers-reduced-motion: reduce)` 全局禁用动画，HeroNumber count-up 也有独立 fallback
4. **Token 系统纪律性强** — 无硬编码颜色，所有颜色走 `--background/--foreground/--primary` 等 token，暗色模式完整
5. **i18n 全覆盖** — 所有 UI 文字走 `t()`，日期/货币用 `Intl.NumberFormat` / `Intl.DateTimeFormat` 按 locale 格式化
6. **Focus-visible 样式一致** — button / input / select / popover 都有 `focus-visible:ring-3 ring-ring/50`，3px 焦点环
